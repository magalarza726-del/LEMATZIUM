LEMATZIUM.

Análisis de ensayos de tracción

Suite de herramientas para importar datos experimentales, revisar curvas, calcular propiedades de materiales y preparar reportes técnicos.

Paquete de descarga pendiente de publicación.

Herramientas

Tracción de metales

Curvas de esfuerzo y deformación, fluencia, Rp offset, esfuerzo máximo y elongación.

Tracción de plásticos

Revisión de datos de ensayo, geometría de probetas y resultados con enfoque ISO 527.

Reportes e incertidumbre

Exportación de reportes Word y gráficas, y edición de fuentes de incertidumbre.

Instalación

  1. Instala Python 3.13 en Windows 10 u 11.
  2. Descarga y extrae el paquete cuando esté disponible.
  3. En la carpeta del programa ejecuta python -m pip install numpy pandas matplotlib openpyxl pyxlsb xlrd pillow python-docx pypdf PySide6 google-genai sounddevice.
  4. Abre run_lematzium_dev.bat.

GitHub Pages aloja esta página informativa; la aplicación original se ejecuta localmente. Los resultados deben ser revisados por un analista antes de emitir reportes.
